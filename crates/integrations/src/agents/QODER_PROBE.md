# Borrowed Qoder collaboration proof

`qoder_probe.rs` owns the selected normally logged-in client, private challenge,
installed Skill verification and supervised process lifetime. Qoder reads its
own authentication data. The probe does not import or inspect credential bytes.

`qoder_probe_http.rs` requires a correlated native Skill call, a user-array loaded
Skill receipt, and the exact result of running the selected public HiRoute CLI.
Assistant claims, a string-shaped message, another tool call or file absence
cannot replace these observations. The request and process budgets remain fixed.

On Windows, `qoder_probe_skill_diagnostic.rs` also owns the production retained
Skill binding. Before launch it opens the original directory and `SKILL.md`
without following reparse points, retains their native identities and permissions,
and verifies the entire file digest. It separately proves the canonical name
opens that same directory. Only those two names and their disk-prefix/case
spellings may be queried; UNC, device, stream, parent and foreign paths fail.

One actual user-array text must contain the LF header, an admitted directory and
the exact expected body under the existing outer-whitespace rule. Both sides of
that query must retain the same directory/file identities, single-link file,
the captured Owner/DACL/read-only permissions and original content. These are
before/after observations; they do not claim an immutable lease against arbitrary
transient writes by the same user or unchanged SACL/MIC fields. Missing binding
is a failure.
Linux keeps its exact literal directory receipt rule.

Closed receipt diagnostics are compiled only for tests. Their shape, identity
and body dimensions help explain failures, but they never authorize a match.
Native controls prove ordinary/verbatim equivalence and reject changed content
or permissions, reparse/foreign paths, split candidates and altered message
shapes. Account-free controls do not establish logged-in business acceptance or
upstream provider-account inference.

Output diagnostics also remain test-only. The live size guard and final bounded
read are distinct: a final open/read failure can carry the same error caption as
oversize output. `qoder_probe_output_diagnostic_tests.rs` covers real owned-file
oversize, missing-path and sampling failures. Closed observations retain the
phase, held-file length and I/O kind/code; unknown and `other` errors do not prove
a size violation. Sampling happens only after the native scope stops because a
cloned handle shares its seek pointer. No output text or path is published, and
missing observations in older evidence remain unknown.

## Windows Bash command

Qoder CLI 1.1.65's Bash tool uses Git Bash on Windows; its separate PowerShell
tool does not change Bash syntax. The command producer reuses native executable
admission, verifies that the ordinary drive/forward-slash spelling opens that
same file, and uses POSIX single-quote escaping. Unix keeps its released escaping.
The HTTP matcher still requires the complete original CLI baseline after its
existing edge trim; equivalent JSON, internal newline conversion or SDK framing
remain mismatches.

`qoder_probe_windows_cli.rs` is an explicit account-free native control. Its
`HIROUTE_VALIDATION_GIT_BASH_BINARY` is only a validation selector, not a product
or Worker dependency. The native ProgramFiles Git installation binds the held
wrapper, actual Bash, Windows Git and MSYS DLL through file identity, permissions,
image bytes and ancestor leases. Bash must import MSYS and must not import Cygwin
in either ordinary or delayed imports. Its GNU compiler triplet may be `msys` or
`cygwin`; the triplet alone cannot admit another distribution. Wrapper and actual
shell version output must agree, and the same installation's Git must identify its
Windows release. This does not prove general dynamic DLL search behavior.
Old PowerShell syntax must fail actual Bash parsing;
the new literal special-character path must execute this candidate's CLI and
return its exact baseline. Ordinary/verbatim identity, reparse rejection and
natural Job emptiness stay required. Missing images fail the explicit case;
this does not replace the normally logged-in Qoder Main business case.
