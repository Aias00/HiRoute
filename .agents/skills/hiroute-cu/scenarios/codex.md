# CODEX: connect, enable cycles and restore the original connection

Use a published plan, native client and protected original configuration. Prepare
a verified alternate control entry when modifying the executor's own connection.
Contract: `issue-spec/specs/agent-connections/spec.md`. Minimum smoke saves via UI,
reopens, makes a real request from the tested client, disables and makes a real
request through its restored original connection. Desktop/CLI scopes are separate;
reuse the plan. Extend auth/save/recovery with repeated saves, enable cycles and
restoration; catalog/protocol changes with model selection/tool continuation.
Only [NAV-02](nav-codex.md) has a batch script, not the connection writes.

1. Configure the actual Agent UI's target, allowed plans and default; no invented modes.
2. Reopen, select the model and make actual Desktop and CLI requests as selected.
   Catalog visibility alone does not establish access.
3. Perform at least three enable/disable/re-enable cycles, checking self-generated
   false drift, authentication and repeated-save errors.
4. Verify retained original-model access for the selected mode and clear rejection
   of disallowed models; finally disable and call the original connection.

Separate auth, catalog and provider errors. Observe drift before changing fields,
never clear configuration. Restore owned fields, preserving unrelated edits. CLI
and another machine do not replace local Desktop evidence. Report the current
revision/results; old navigation does not prove connection acceptance.
