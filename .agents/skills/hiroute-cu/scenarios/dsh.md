# DSH: public configuration and native ACP

Use the exact Mac Desktop candidate, dedicated HOME/DSH_HOME/data, controlled
model source and official DSH CLI with its supported Node. Models may be controlled;
native CLI/ACP, installed user Skill, public HiRoute CLI and tool artifacts must be real.

1. Verify candidate SHA, window/daemon PID, build lease, isolated roots and both
   actual Debug levels; never operate a daily instance.
2. Models scans/imports explicitly configured static provider/model. Save/restart
   persists it, leaves native files untouched and scanning makes no inference call.
3. Plan selects the source, enables DeepSeek Harness Worker, confirms the actual CLI
   and publishes/readbacks. Require native CLI only, no ACP adapter or SDK/Node
   selector; missing CLI offers the official npm command and Node prerequisite.
4. Save/reopen Responses and Messages model plans. Native execution consumes the
   persisted Web patch with independent upstream receipt, no call-time route/key
   injection. Task enable/edit/disable follows common interactions without a
   verification button or state.
5. A real main Agent loads the installed user Skill using native `skill` and invokes
   public `hiroute worker`; Desktop shows matching task/run/DSH/file. Publish a
   Worker-protocol change via UI and wait/read back its Operation/revision; Continue
   through public CLI retains original task protocol/native session and a new run.
   Do not revert the current plan to bypass frozen-task behavior.
6. UI cancels one of two tasks, witnessing stopped target descendants/effects and
   successful neighbor. Missing history explicitly rejects instead of new-session
   substitution.
7. Restore model/task facets independently; default references prevent deletion and
   other facets/foreign providers/native files remain unchanged. Retain only
   requested test state for final review.

Reuse [Pi interaction](pi.md) principles for actual controls, Operation waits and
exact task/run lookup. Preserve private diagnosis, distinguish product/fixture/
environment/expected rejection, and observe unknown state before retrying. Do not
bypass saves with database changes. Evidence boundaries:
[DSH acceptance](../../../../tools/product-e2e/tests/DSH_INTEGRATION.md) and
[code map](../../../../docs/code-map/worker-context.md#deepseek-harness).
Record selected release and actual coverage in the Issue/PR; WebView/backend
acceptance does not claim physical-mouse/full-screen, arbitrary providers/plugins
or cross-version Continue.
